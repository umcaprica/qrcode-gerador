# Gerador de QR Code — Grupo EGB

Gerador de QR code estático: o conteúdo (link ou texto) é gravado direto no desenho do código, gerado no navegador — sem servidor, link encurtado ou serviço externo por trás.

**Site:** https://qrcode-gerador-kappa.vercel.app

## Funcionalidades

- Gera QR a partir de qualquer link ou texto
- Nível de correção de erro configurável (L/M/Q/H)
- Exportação em PNG em qualquer tamanho (64px–4096px), com atalhos para 256/512/1024/2048/4096px
- 100% estático — abre como uma página HTML única, sem build, sem dependências de servidor

## Deploy

Qualquer push na branch `main` atualiza automaticamente o deploy de produção no Vercel.
