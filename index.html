Gerador de QR Code

Gere um QR code estático a partir de um link ou texto. O conteúdo fica gravado diretamente no código — nada de redirecionamento, nada que expire.

QR fixo: o código é gerado no seu navegador e o conteúdo é lido diretamente do desenho — não depende de um servidor, link encurtado ou serviço externo para funcionar.
